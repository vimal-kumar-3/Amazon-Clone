# Amazon-Style Storefront Demo

A responsive e-commerce storefront inspired by Amazon, built using HTML, CSS, and JavaScript.

## Features
- Product search and category filtering
- Sort products by price and rating
- Add, remove, and update cart quantities
- Wishlist management
- Cart and wishlist persistence using localStorage
- Responsive product grid and navigation
- Demo checkout, account, delivery, and orders interfaces

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Browser localStorage

## How to Run
1. Clone or download this repository.
2. Keep `index.html`, `style.css`, and `script.js` in the same folder.
3. Open `index.html` in your browser, or use VS Code Live Server.
4. Ensure you have an internet connection for external product images, icons, and fonts.

## Limitations
This is a frontend learning project, not the official Amazon website. It uses sample products and prices and does not provide real authentication, payment processing, inventory management, or backend order handling.
